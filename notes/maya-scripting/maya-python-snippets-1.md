## 1.1  Echo: From Clicks to Code (A)  [MEL - read only, do not run in Python tab] 

Maya can show the MEL command generated by a UI action. This is useful for discovering what an operation does; this block is MEL syntax and should not be pasted into the Python tab.


```MEL
// History panel after you click the Joint tool:
joint -p 0 0 0;
joint -p 0 5 0 -n "test";
// Result: test //
```

## 1.1  Echo: From Clicks to Code (B) 

The Python version calls the same joint-creation commands through `maya.cmds`. The `cmds` module is Maya’s command interface for scene operations.

## 2.1  Build the Test Arm (A) 

These commands create three joints in sequence. Maya parents each newly created joint under the previously selected joint, forming a simple hierarchy.



```Python
import maya.cmds as cmds

cmds.select(clear=True)
cmds.joint(name="L_shoulder_jnt", position=(2, 15, 0))
cmds.joint(name="L_elbow_jnt",    position=(6, 15, -0.5))
cmds.joint(name="L_wrist_jnt",    position=(10, 15, 0))
```

## 2.1  Build the Test Arm (B) 

`edit=True` changes an existing joint chain. Joint orientation defines the local axes that rotations and rig controls will use.

## 2.3  Create, Query, Edit 

A query reads scene data, while a set/edit command changes it. `worldSpace=True` asks for a position in world coordinates rather than relative to a parent.


```Python
jnt = "L_elbow_jnt"

print(cmds.xform(jnt, query=True, worldSpace=True, translation=True))
print(cmds.getAttr(f"{jnt}.translateX"))

cmds.setAttr(f"{jnt}.radius", 2)
cmds.xform("L_wrist_jnt", worldSpace=True, translation=(10, 14, 0))
```

## 3.1  Variables and Types 

Variables give useful names to values. Maya scripts commonly use strings for node names, numbers for dimensions, booleans for options, lists for collections, and tuples for fixed coordinate values.


```Python
joint_count = 3
radius = 1.5
side = "L"
is_ik = True
joints = ["L_shoulder_jnt", "L_elbow_jnt", "L_wrist_jnt"]
pos = (2, 15, 0)

for value in (joint_count, radius, side, is_ik, joints, pos):
    print(type(value), value)
```

## 4.2  Four Ways to Build a Name 

All four forms assemble the same name. F-strings are usually easiest to read; `:02d` formats an integer with at least two digits, such as `01`.


```Python
side = "L"
part = "arm"
kind = "ctrl"
num = 1

print(side + "_" + part + "_" + kind + "_" + str(num).zfill(2))
print("%s_%s_%s_%02d" % (side, part, kind, num))
print("{}_{}_{}_{:02d}".format(side, part, kind, num))
print(f"{side}_{part}_{kind}_{num:02d}")
```


## 4.4  Taking Names Apart 

`split()` turns a delimited name into a list of parts; unpacking assigns those parts to separate variables. `join()` combines parts back into one string.


```Python
name = "L_arm_ik_ctrl"
parts = name.split("_")
print(parts)

side, part, mode, kind = parts
print(side, part, mode, kind)

print("_".join(["R", part, mode, kind]))
```


## 4.5  The Replace Bug Hunt (A)  [CONTAINS ERRORS ON PURPOSE] 

`replace()` changes every matching substring, not just a leading side prefix. The examples show why blind replacement can alter a name unexpectedly.


```Python
print("L_arm_ctrl".replace("L_", "R_"))
print("L_leg_L_ctrl".replace("L_", "R_"))
print("FL_hoof_ctrl".replace("L_", "R_"))
```

## 4.5  The Replace Bug Hunt (B)  [CONTAINS ERRORS ON PURPOSE] 

`startswith()` checks only the beginning of a name, so it avoids changing an `L_` that appears later in a word such as `FL_hoof_ctrl`.

```Python
name = "FL_hoof_ctrl"

if name.startswith("L_"):
    print("R_" + name[2:])
else:
    print("No L_ prefix, leaving alone:", name)
```

## 5.2  Control Inside a Group 

A group can hold the control at the joint location while the control itself keeps clean local transforms. This offset-group pattern is common in rigging.



```Python

                    radius=2, constructionHistory=False)[0]
grp = cmds.group(ctrl2, name="demoB_grp")

```

## 7.5  Build a Spine with a Loop

## 8.2  make_ctrl: One-Call Control (A) 

This first part defines the function and checks that the target exists and the requested control name is available before creating anything.

See: Snippet 3 (complete make_ctrl)

```Python
def make_ctrl(name, target, radius=1.0, color=17):
    """Make a zeroed circle control at target.
    Returns (ctrl, group)."""
    if not cmds.objExists(target):
        cmds.warning(f"Target '{target}' does not exist.")
        return None, None
    if cmds.objExists(f"{name}_ctrl"):
        cmds.warning(f"'{name}_ctrl' already exists.")
        return None, None
```

## 8.2  make_ctrl: One-Call Control (C)  [continues the function from the previous slide] 

The shape override sets display color. Locking scale and visibility helps prevent accidental edits to channels the rig intends to control.

See: Snippet 3 (complete make_ctrl)

```python
shape = cmds.listRelatives(ctrl, shapes=True)[0]
    cmds.setAttr(f"{shape}.overrideEnabled", True)
```

## Snippet 3: make_ctrl Complete 

This is the full reusable version assembled from the earlier steps. It returns both the control curve and its parent group for later rigging operations.

Used with: 8.2, 8.3 (the finished function)

```Python
import maya.cmds as cmds
 
def make_ctrl(name, target, radius=1.0, color=17):
    """Make a zeroed circle control at target.
    Returns (ctrl, group)."""
    if not cmds.objExists(target):
        cmds.warning(f"Target '{target}' does not exist.")
        return None, None
    if cmds.objExists(f"{name}_ctrl"):
        cmds.warning(f"'{name}_ctrl' already exists.")
        return None, None
 
    ctrl = cmds.circle(name=f"{name}_ctrl", normal=(1, 0, 0),
                       radius=radius, constructionHistory=False)[0]
    grp = cmds.group(ctrl, name=f"{name}_grp")
    cmds.matchTransform(grp, target, pos=True, rot=True)
 
    shape = cmds.listRelatives(ctrl, shapes=True)[0]
    cmds.setAttr(f"{shape}.overrideEnabled", True)
    cmds.setAttr(f"{shape}.overrideColor", color)
 
    for attr in ["scaleX", "scaleY", "scaleZ", "visibility"]:
        cmds.setAttr(f"{ctrl}.{attr}", lock=True,
                     keyable=False, channelBox=False)
 
    return ctrl, grp
```

## AUTORIG STARTER FILE (also saved as Autorig_Starter.py) 

This is a small starting point for a rigging script: one function creates a control, and another helper mirrors a left-side name. The note describes a file copy; keep this reference in sync with that script if you edit the starter separately.


```Python
import maya.cmds as cmds

# 
# AUTORIG STARTER FILE  (Python in Maya, Week 1)
# Naming convention: side_part_kind   e.g. L_arm_ctrl, L_arm_grp, L_arm_jnt
# Rule: do it by hand once. The second time, make it a function.
# 

def make_ctrl(name, target, radius=1.0, color=17):
    """Make a zeroed circle control at target.
    Returns (ctrl, group)."""
    if not cmds.objExists(target):
        cmds.warning(f"Target '{target}' does not exist.")
        return None, None
    if cmds.objExists(f"{name}_ctrl"):
        cmds.warning(f"'{name}_ctrl' already exists.")
        return None, None

    ctrl = cmds.circle(name=f"{name}_ctrl", normal=(1, 0, 0),
                       radius=radius, constructionHistory=False)[0]
    grp = cmds.group(ctrl, name=f"{name}_grp")
    cmds.matchTransform(grp, target, pos=True, rot=True)

    shape = cmds.listRelatives(ctrl, shapes=True)[0]
    cmds.setAttr(f"{shape}.overrideEnabled", True)
    cmds.setAttr(f"{shape}.overrideColor", color)

    for attr in ["scaleX", "scaleY", "scaleZ", "visibility"]:
        cmds.setAttr(f"{ctrl}.{attr}", lock=True,
                     keyable=False, channelBox=False)

    return ctrl, grp


def mirror_name(name):
    """L_ name in, R_ name out. Anything else: warn and return None."""
    if name.startswith("L_"):
        return "R_" + name[2:]
    cmds.warning(f"'{name}' does not start with L_")
    return None
```
